# Worked example: Golden Island Cruises — Plan on a Page

**Purpose**: Deliver distinctive, well-run phinisi charter experiences
in Lombok that build a sustainable, repeat-visit business.

**Current state**:
- Day-trip and multi-day products are established and profitable
- Booking process is manual and staff-dependent, creating a response-time
  bottleneck
- No second route beyond current offering; growth is currently capacity-
  constrained, not demand-constrained

**Priorities**:
1. **Fix the booking bottleneck** — People: cross-train a second person
   on inquiries. Process: define a documented backup process. Systems:
   move off the shared spreadsheet onto a dedicated booking platform.
2. **Validate the Gili route opportunity** — People: ops lead runs
   scouting. Process: apply structured unit economics before committing.
   Systems: none new required at validation stage.
3. **Protect service quality while growing** — People: none new.
   Process: track review rating as a guardrail metric alongside booking
   growth. Systems: none new required.

Note only three priorities, each concrete enough to check progress
against — not an exhaustive list of everything worth doing (the loyalty
program and website redesign ideas from earlier prioritization work are
real, just not among the top 3-5 for this page).
