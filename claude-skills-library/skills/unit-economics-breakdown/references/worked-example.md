# Worked example: day-trip vs. multi-day charter, per guest

Illustrative figures only — replace with real numbers for actual use.

## Day-trip product (per guest)
- Revenue per guest: $100
- Variable costs per guest: fuel share $15, food/provisioning $10,
  booking platform fee (8%) $8 → total variable $33
- **Contribution margin per guest: $67 (67%)**
- Fixed costs allocated per guest (crew base salary, boat maintenance,
  insurance, divided across expected annual guest volume): $25
- **Fully-loaded profit per guest: $42**

## Multi-day charter product (per guest)
- Revenue per guest: $600 (3-day package)
- Variable costs per guest: fuel share $60, food/provisioning $80,
  booking platform fee (8%) $48 → total variable $188
- **Contribution margin per guest: $412 (69%)**
- Fixed costs allocated per guest (same cost categories, but multi-day
  trips use more crew-days and boat-days per guest, so fixed allocation
  is proportionally higher): $150
- **Fully-loaded profit per guest: $262**

## So what, illustrative

Both products show similar contribution margin percentage (~67-69%), so
neither is more "efficient" per revenue dollar in variable-cost terms.
But the multi-day product generates far more fully-loaded profit per
guest in absolute terms ($262 vs $42) — which matters most when boat/crew
capacity, not guest count, is the actual constraint (i.e. each available
boat-day should ideally go to the higher-profit-per-day use, if demand
allows).

This is the kind of insight unit economics is built to surface: not just
"which is more profitable per guest" but "which use of a scarce resource
(boat-days) generates more profit," which sometimes points to a different
answer than the raw margin percentage would suggest on its own.
