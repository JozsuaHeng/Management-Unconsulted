# Positioning & Pitch Crafter

## When to use this

The user needs a clear, sharp way to describe a business, product, or
offering — for a pitch, a website, an introduction, or just to clarify
their own thinking about what they actually offer and to whom.

## When NOT to use this

- What's being offered isn't actually decided yet — positioning describes
  something that exists or is concretely planned; if the offering itself
  is still undefined, that's a different (earlier) conversation.

## Workflow

1. **Use the standard positioning statement structure** as a forcing
   function, even if the final pitch doesn't use this exact template:
   *"For [specific target customer], who [need/problem], [offering] is a
   [category] that [key benefit]. Unlike [main alternative], we
   [key differentiator]."*
2. **Make the target customer genuinely specific**, not "everyone" or
   "people who like boats" — a positioning statement that could describe
   any customer doesn't actually position anything.
3. **Name the real alternative**, not a strawman. The alternative to a
   Lombok boat charter might be a resort stay, a different destination
   entirely, or a competitor — pick the one actually being chosen against
   most often, since the differentiator only means something relative to
   a real alternative.
4. **State the differentiator as a genuine reason to choose this over
   that alternative** — not a generic claim ("quality service") that any
   competitor could also claim. If the only real differentiator is price,
   say so plainly rather than dressing it up as something else.
5. **Once the structured statement is solid, adapt it into pitch length**
   — a natural-sounding 15-30 second spoken version loses the template
   scaffolding but keeps the same core content (who, what, why better).
6. **Check it against a simple test**: would a competitor's positioning
   statement, with the names swapped, sound just as true? If yes, the
   differentiator isn't sharp enough yet.

## Output format

```
## Positioning: [business/offering]

**Structured statement**: For [target customer], who [need], [offering]
is a [category] that [benefit]. Unlike [alternative], we [differentiator].

**Elevator pitch (spoken version, ~20-30 seconds)**: [natural-sounding
paragraph version]

### Differentiation check
Would this sound just as true with a competitor's name swapped in?
[Yes/No, and if yes, what needs to get sharper]
```

## Common pitfalls

- A target customer so broad it doesn't actually narrow anything ("for
  travelers").
- A strawman alternative instead of the real thing being chosen against.
- A differentiator so generic it could apply to any competitor ("quality
  and great service").
- Skipping the swap-test, so a weak differentiator goes unnoticed.

## Quality checklist

- [ ] Target customer is genuinely specific
- [ ] The named alternative is the real one, not a strawman
- [ ] The differentiator is a real reason to choose this over that
      specific alternative
- [ ] Passes the "swap the competitor's name in" test
