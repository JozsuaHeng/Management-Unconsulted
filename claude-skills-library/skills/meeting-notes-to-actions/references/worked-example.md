# Worked example

Raw notes (illustrative): "Talked about the Gili route again. Jozsua
thinks we should go ahead with a scouting trip, maybe next month. Need to
find a dock contact there — nobody's done that yet. Also discussed
whether to price it same as current multi-day trips or higher, no
agreement yet, need to look at the unit economics first. Ops team should
also check crew availability for a scouting trip once we have a date."

### Output

**Context**: Discussion about next steps for the potential new Gili
multi-day route.

**Decisions made**
- Proceed with a scouting trip for the Gili route (timing not yet fixed
  beyond "next month" as a rough target).

**Action items**
- [ ] Find and confirm a local dock contact near the Gilis — Owner: not
  assigned — Due: not set (needed before scouting trip can be scheduled)
- [ ] Run unit economics on Gili route pricing (same vs. higher than
  current multi-day trips) — Owner: not assigned — Due: not set
- [ ] Check crew availability for a scouting trip — Owner: Ops team — Due:
  once a scouting trip date is set (dependent on the two items above)

**Open questions**
- Should the Gili route be priced the same as current multi-day trips or
  higher? (needs the unit economics work above before deciding)
- What's the actual target date for the scouting trip? ("next month" was
  mentioned but not confirmed)

Note how "proceed with a scouting trip" is a real decision (something was
settled), while pricing is correctly left as an open question rather than
forced into a decision that wasn't actually made — and two action items
have no assigned owner, which is flagged rather than guessed.
