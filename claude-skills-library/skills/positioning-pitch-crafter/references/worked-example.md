# Worked example: Golden Island Cruises

Weak starting version (illustrative): "We offer amazing boat trips in
Lombok with great service and beautiful boats."

Problem: could describe almost any charter operator in the region — fails
the swap test immediately.

### Sharpened version

**Structured statement**: For travelers who want an authentic,
uncrowded island experience without giving up comfort, Golden Island
Cruises is a phinisi boat charter operator that combines traditional
Indonesian craftsmanship with a genuinely experienced local crew. Unlike
large-group day-trip operators, we run smaller, owner-operated charters
where the crew's local knowledge shapes the actual route, not just a
fixed itinerary.

**Elevator pitch (spoken)**: "We run phinisi boat charters out of
Lombok — traditional wooden boats, but with real comfort. What makes us
different from the big day-trip operators is that we're small and
owner-run, so the crew's actual local knowledge shapes where you go,
instead of everyone getting the same fixed stops."

### Differentiation check
Would a large day-trip operator's positioning sound just as true with
"Golden Island Cruises" swapped in? No — "large-group," "fixed
itinerary," and "owner-operated, crew-shaped route" are specific claims
that wouldn't fit a big-fleet operator's actual model. That's what makes
this differentiator real rather than generic marketing language.

Note what changed from the weak version: "great service" (unfalsifiable,
generic) became "owner-operated, crew's local knowledge shapes the
route" (specific, checkable, genuinely differentiating from a named
alternative type of competitor).
